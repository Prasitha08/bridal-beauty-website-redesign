BRIDAL BEAUTY HUB — WEBSITE UI REDESIGN

FILES
1. index.html
   Responsive, self-contained website redesign concept. Open in Chrome/Edge.
   Navigation scrolls to sections; buttons/cards show demo feedback.

2. Website_UI_Redesign_Case_Study.pdf
   Includes project overview, heuristic evaluation checklist, mood board,
   colour palette, typography, page structure, responsive rules and conclusion.

PUBLISH TO GITHUB PAGES
1. Sign in at https://github.com/
2. Create a PUBLIC repository named bridal-beauty-website-redesign
3. Upload index.html and Website_UI_Redesign_Case_Study.pdf to the root.
4. Open Settings > Pages.
5. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for the published URL. It will look like:
   https://YOUR-GITHUB-USERNAME.github.io/bridal-beauty-website-redesign/
7. Open the URL in an incognito/private window to verify it before submission.

IMPORTANT
This is a redesign concept based on the Bridal Beauty Hub app/project idea, not
a redesign of a supplied live website. Sample provider names, locations and
prices are fictional placeholder content. The prototype is not connected to
authentication, payments, live search or a booking database.
